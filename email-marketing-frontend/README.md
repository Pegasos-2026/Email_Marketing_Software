# Email Marketing Frontend

This project is a frontend application for an email marketing software built using React and TypeScript. It provides a user-friendly interface for managing email campaigns, viewing reports, and adjusting settings.

## Features

- **Campaign Management**: Create, edit, and delete email campaigns.
- **Dashboard**: Overview of key metrics related to email marketing performance.
- **Email Editor**: User interface for composing and editing email content.
- **Reports**: Analytics and performance reports for email campaigns.
- **Settings**: Configuration options for user preferences and account information.

## Getting Started

To get started with the project, follow these steps:

1. **Clone the repository**:
   ```
   git clone <repository-url>
   cd email-marketing-frontend
   ```

2. **Install dependencies**:
   ```
   npm install
   ```

3. **Run the application**:
   ```
   npm start
   ```

4. **Open your browser** and navigate to `http://localhost:3000` to view the application.
